# School Hub Central

The School Management portal is the centralized portal for accessing all modules based on role and access level. Modules are not suppose to be on the landing page, they are accessed on the respective School Management portal.

The landing page must be used for role selection and login only

The number of modules available to a user after login must be based on their access level.

Set up the landing page and the School Management portal with all necessary features as well as placeholders and reference for all modules while I provide the respective modules later.

Ensure that users see only the modules accessible to them based on their role and access level.

Preserve the existing login-only authentication and forgot password system such that users can only login, and their password can be reset by admin only.

Initial Super admin account and school manager account must be created via the setup.

The role selection page in the attached image is the landing page while the School Management Portal page with all modules is the centralized unified dashboard for all users after login.

Maintain the unification and centralization intent if it is ultimate for scalability, performance, and reusable
